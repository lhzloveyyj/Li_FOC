1. 为什么需要 FOC

FOC 的全称是 Field Oriented Control，通常翻译为磁场定向控制。 它要解决的核心问题不是“让电机转起来”，而是让电机像直流电机一样容易、稳定、精确地控制。

简单说：普通控制更像是在“给电机通电试着让它转”，FOC 则是在“明确控制磁场方向和转矩大小”。

1.1 只让电机转起来，其实不难

对三相无刷电机来说，只要三相绕组中产生一个旋转磁场，转子就会被这个磁场拖着转。 最简单的做法是六步换相，或者直接给三相输出按顺序变化的电压。

这种方法能让电机转，但它并不关心一个更细的问题： 当前输出的电压和电流，有多少真正变成了转矩，有多少只是浪费在发热或磁场错位上。

控制目标 普通控制的特点 容易出现的问题
让电机转 按固定顺序换相或输出旋转电压 低速抖动、噪声大、转矩不连续
控制速度 调占空比或调电压大小 负载变化时速度容易掉，动态响应不细腻
控制力矩 通常只能间接依赖电流或电压 不知道电流方向是否正好用于产生有效转矩

1.2 FOC 的关键价值：把复杂交流控制变成 dq 直流控制

FOC 的核心动作，是把三相电流变换到跟随转子一起旋转的坐标系里。 在这个旋转坐标系中，电流会被拆成两个分量：

Iq：转矩电流

主要负责产生转矩。想让电机更有力，通常就是增大 Iq。

Id：励磁电流

主要影响磁场方向。表贴式永磁同步电机中，常见目标是让 Id = 0。

这样一来，控制器就不用直接面对三相交流电流，而是控制两个近似直流量： Iq 管力矩，Id 管磁场。 这就是 FOC 能把无刷电机控制得更平滑、更安静、更精准的根本原因。

1.3 FOC 解决了哪些实际问题

低速平滑 电流连续变化，转矩脉动小，电机低速不容易一顿一顿。
噪声更低 相比粗糙换相，磁场旋转更细腻，机械噪声和电磁噪声更容易控制。
转矩可控 通过 Iq 直接控制出力大小，负载变化时更容易稳住。
效率更高 尽量让电流用在产生有效转矩上，减少无效电流和发热。
适合闭环 电流环、速度环、位置环可以层层叠加，形成精确伺服控制。

2. Clarke 变换

Clarke 变换做的事情，是把三相静止坐标里的电流 Ia、Ib、Ic， 换成两相静止坐标里的 Ialpha、Ibeta。它还没有用到转子角度， 只是把三相电流矢量放到一个更容易计算的二维直角坐标系里。

可以先这样理解：三相电流本来相差 120 度，不方便直接算控制量；Clarke 变换把它们投影到 alpha 和 beta 两根互相垂直的轴上，后面的 Park 变换再用电角度把 alpha/beta 旋转成 d/q。

2.1 为什么三相可以变成两相

电机三相绕组在正常情况下满足一个重要关系： 

Ia + Ib + Ic = 0

也就是说，三相里只有两相是独立的。只要知道任意两相，第三相就可以算出来： 

Ic = -(Ia + Ib)

所以项目里的 Clarke 函数只接收 Ia 和 Ib，没有把 Ic 作为输入。

2.2 本项目里的公式

当前代码使用的是幅值不变形式： 

Ialpha = Ia
Ibeta  = (Ia + 2 * Ib) / sqrt(3)

对应到代码就是 FOC.c 里的 clarke_transform()： 

void clarke_transform(float Ia, float Ib, float *Ialpha, float *Ibeta)
{
    *Ialpha = Ia;
    *Ibeta = (1.0f / FOC_SQRT3) * (Ia + 2.0f * Ib);
}
公式里的量 代码里的量 作用
Ia Ia 参数 进入 Clarke 的 A 相电流，直接作为 Ialpha。
Ib Ib 参数 和 Ia 一起计算 Ibeta。
sqrt(3) FOC_SQRT3 定义在 foc_config.h，当前值是 1.732f。
Ialpha pFOC->iAlpha α 轴电流，后面作为 Park 变换输入。
Ibeta pFOC->iBeta β 轴电流，后面作为 Park 变换输入。

2.3 在 FOC 主流程里怎么调用

FocContorl() 每个 PWM 周期都会先把 ADC 值换算成三相电流： 

pFOC->Ia = (pFOC->current.adA - pFOC->current.voltageAOffset) / 4096.0f
           * FOC_ADC_REF_VOLTAGE / FOC_GAIN / FOC_SHUNT_R;
pFOC->Ib = (pFOC->current.adB - pFOC->current.voltageBOffset) / 4096.0f
           * FOC_ADC_REF_VOLTAGE / FOC_GAIN / FOC_SHUNT_R;
pFOC->Ic = (pFOC->current.adC - pFOC->current.voltageCOffset) / 4096.0f
           * FOC_ADC_REF_VOLTAGE / FOC_GAIN / FOC_SHUNT_R;

然后根据当前 SVPWM 扇区做电流重构。这个函数利用的就是 Ia + Ib + Ic = 0： 

CurrentReconstruction(g_pMotor, PSVpwm, pFOC->Ia, pFOC->Ib, pFOC->Ic);

最后才进入 Clarke 和 Park： 

clarke_transform(-pFOC->Ia, -pFOC->Ib, &pFOC->iAlpha, &pFOC->iBeta);
park_transform(pFOC->iAlpha, pFOC->iBeta, pFOC->correctedAngle,
               &pFOC->id, &pFOC->iq);
这里传入的是 -pFOC->Ia 和 -pFOC->Ib，说明当前采样方向和控制坐标定义相反。 所以代码在进入 Clarke 前先取反，把电流方向统一到控制算法使用的方向。

2.4 这一模块先记住什么

  • CurrentReconstruction() 负责把三相电流补全，依据是 Ia + Ib + Ic = 0。
  • clarke_transform() 负责把 Ia/Ib 变成 iAlpha/iBeta。
  • iAlpha/iBeta 还是静止坐标系，真正变成 Id/Iq 要等下一步 Park 变换。
